# The development environment is the first slice of Agentinc OS

Agentinc OS is meant to cover more of life than code (a home area and others come later), but the first thing built is the development environment: talking to Evee, tracking Tickets, and agents doing coding work. It lives in this repo beside the SDK rather than in a separate app or repo, so the SDK is used by its real consumer and never copied into a second place to drift.
