# Autonomous effects start from a Ticket

Autonomous agent work with effects requires an assigned Ticket; a Conversation reply or inline inference does not. Evee creates and assigns Tickets through the same authorized commands as a human, and each Automation occurrence creates and assigns its own Ticket. A Ticket has one of four statuses: Backlog, To do, In progress, Done. This keeps effectful work tracked and inspectable without making every reply a Ticket.
