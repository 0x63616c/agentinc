# AgentInc 0.3.2

- Fix a crash when an update check changes the Software Update window from “Checking for updates” to the result. Update windows now have one owner, so they can close safely during checks, downloads, and installation.
- If you are on 0.2.0 or 0.3.1 and Check for Updates crashes, install 0.3.2 from the release download once. The installed updater cannot repair its own window ownership before the check completes.
