# AgentInc 0.8.0

## Tabs and navigation

- Open multiple tabs with ⌘T, close with ⇧⌘W or the hover X, and switch with ⇧⌘[ / ⇧⌘]. These shortcuts also work inside the native terminal.
- Curved tabs stay within a scrollable strip, reveal the selected tab, and keep long titles and close controls inside the window.
- Each tab remembers its own Ticket and Conversation history across Back, Forward and app restarts. Existing saved layouts migrate automatically.
- A compact sidebar keeps Search, navigation icons and the profile avatar available. The expanded sidebar has more room for labels.
- Profile and Support menus fit beside each other. A white sidebar update indicator appears when an update is available; ⇧⌘U checks for updates.

## Consistent controls

- Automation assignment uses the shared agent dropdown.
- Monospaced identifiers follow the selected interface font: SF Mono with System, Menlo with Helvetica Neue.

## API and terminal

- Conversations use `/v1/conversations` and `/v1/conversations/commands`. The old `/v1/state`, `/v1/commands`, CLI `product` group and deprecated Todo commands have been removed.
- Terminal APIs use the `Terminal` name and `/v1/terminals`; Automation snapshots expose `automations`.
- `ainc terminal attach <id>` connects to a persistent terminal. The bundled app uses the same CLI path.
- Human-facing Ticket keys are consistent across the app, CLI and agent tools; command arguments and JSON ids remain numeric.

## Reliability and builds

- Daemon SQL is checked at compile time, with committed offline metadata and database-backed verification.
- Process-group and terminal ownership are centralized. Event timestamps use the actual event time, and the occurrence-status migration preserves compatibility with older writers.
- The SDK's durable integration tests share one binary, reducing duplicate build artifacts. Native framework dependencies are trimmed and TOML formatting is checked in CI.
