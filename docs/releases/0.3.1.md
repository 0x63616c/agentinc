# AgentInc 0.3.1

This release includes all changes since 0.2.0. Version 0.3.0 was never published.

- Evee now has a full conversation page with streaming replies and launch and loading animations. Navigation is simpler, with a compact profile, repaired Search and Settings, and a fixed status bar.
- Terminal is embedded in the sidebar with Ghostty. Sessions live in the daemon, so panes, splits, and output survive navigation and app relaunches.
- Workspaces organize app context, and the generated `ainc` CLI discovers the installed daemon.
- The new Temporal page shows owner-scoped workflow history.
- Shared native page framing gives Settings, Automations, and other pages consistent layout.
- Release packaging now stages Ghostty themes in the resource layout produced by the build runner.
