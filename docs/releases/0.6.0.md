# AgentInc 0.6.0

- New Connections page holds the ChatGPT sign-in, and Settings, Agents and Terminal are now full pages.
- One consistent look for menus, selects, dialogs, empty states and errors, with British spelling and the `⌘K` shortcut style throughout.
- Times, run states and shortcuts read the same on every page; a new Work page replaces the Temporal history view.
- Agents appear as rounded squares and people as round avatars everywhere.
- The app polls the daemon once for every page and slows down when nothing is running.
- The daemon keeps one ChatGPT connection open instead of starting one per reply, and every Ticket change goes through the same board rules.
- Errors from the daemon now say what went wrong and what to do next.
