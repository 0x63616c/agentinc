# AgentInc 0.6.0

- AgentInc now uses Sparkle behind the existing update windows and settings.
- Future updates can download only the changes between app versions, with a full
  download as a fallback when a delta cannot be applied.
- Update installation flushes the app's state and drains its local daemon before
  restarting into the new version.

This first update still downloads the full app to install the new updater. Your
data stays in place, and the update controls remain familiar.
